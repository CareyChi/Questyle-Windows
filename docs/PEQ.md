# Dongle PEQ

## 原理与范围

侧栏顺序为设备、PEQ、设置、关于。PEQ 使用本项目的 `Questyle.Peq.Native.dll`，不依赖 Equalizer APO 的安装、配置、COM 类或运行进程。本机原理分析和证据单独保存在 `reverse/docs/EQUALIZER_APO_ANALYSIS.md`，原始材料保留在 reverse。

处理链路：Windows 共享模式 PCM → Dongle 端点的本项目 GFX APO → USB 音频驱动 → Dongle。它不是固件硬件 EQ，不发送 USB EQ 指令，不通过捕获/重播系统音频实现。编辑器关闭后，Windows 音频引擎仍可运行已安装的 APO。

前级增益为 `10^(dB/20)`。滤波器依据 [RBJ Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/) 按实际采样率生成二阶 IIR 系数，逐段串联，各声道分别保存历史。支持 1–8 声道、8–384 kHz float32；频段达到或超过当前 Nyquist 频率时拒绝整份配置，不丢掉该频段。实时回调不读文件、不分配/释放堆内存、不等待互斥锁；后台线程加载配置并回收旧状态，新旧配置以约 10 ms 交叉淡入。

## 编辑、文件与状态

- 列表「启用」标题右侧新增默认开启的滤波器总开关。关闭后仅暂停各段滤波器，前级增益保持原值，各行勾选保留并禁用为灰色；图表保留原滤波曲线并变灰，不归零，开启后恢复曲线颜色及原勾选组合。状态按型号保存为 BandsEnabled，旧 JSON 未包含此字段时默认开启；声音写入沿用实时／手动应用模式。二进制仍使用原格式，只在写出时屏蔽滤波器启用位，JSON 保留各段原始选择。文本及外部格式导出反映暂停状态。


- 操作排末尾增加红色「重置」：清空全部滤波器后只保留启用的 PK / 1000 Hz / 0 dB / Q 1，前级和总开关保留；按钮随即变为「撤销重置」，可以恢复完整原列表。开始任意参数编辑（包括尚未输入完整的数值）、增删或导入后清除撤销；切换型号或载入外部配置也清除，频率轴拖动及模式切换保留撤销。重置和撤销沿用自动保存与实时/手动写入规则。
- 前级标签移除单位，`dB` 固定显示在输入框内右侧，独立于数值文本；不能选择、复制或编辑，不拦截鼠标，也不再缩小文本视口。前级框宽为 64 DIP。参数列表类型框和数值框左右间距各为 15 DIP，列宽不变，框宽比本次调整前缩短 12 DIP；腾出的宽度等分到左右间距。滑动开关和对勾框启用背景统一为蓝色。
- 数值框禁用 IME 组字；输入、粘贴和文本变更共用词法/范围校验，非法字符静默拒绝。数值超上限时拒绝输入，拖动/滚轮停在边界；超范围时在框上方渐显合法范围，最后一次尝试 2 秒后渐隐。删除到空或低于下限时直接变为下限。输入中允许符号、小数点和正数下限的数字前缀继续完成数值，按 Enter 或离开时仍不完整/低于下限则归到下限；期间保留上一条有效曲线，不闪出参数错误，也不将中间值写入音频配置。
- 频率轴在全部拖动位置都将原 12–16k 区间宽度的 30% 转移给 10–12k，再将 16k 以上区间的 15% 转移给 12–16k。20–250 Hz 区间按原分配比例缩短 3%，腾出的宽度加给 500–1k Hz，250–500 Hz 保持跨度并平移；频率顺序及范围不变。纵轴文字右对齐并距轴线 5 DIP。鼠标在图内时，沿曲线显示细黑边、少量阴影的抗锯齿白色小圆点，横轴覆盖圆角完整整数频率标签；离开隐藏；被悬停标签遮住的原刻度文字以 140 毫秒淡出，移开后淡入，同一目标不重启动画。破音提示覆盖在图内左上角（左侧 40、顶部 10 DIP），字号与按钮一致为 14，不拦截鼠标，显隐使用 140 毫秒渐变，不改变页面布局。
- 曲线通过 DrawingVisual / StreamGeometry 批量绘制，频率线、标签、白点通过 RenderTransform 移动；鼠标移动与参数输入合并到下一绘制帧，悬停不重建曲线。采用固定对数与线性采样点的并集，并加入各段中心；参数变化时一次传入原生组件，校验与滤波系数只计算一次，幅度预览使用与原复数传递函数等价的实数模平方计算。坐标拖动和悬停复用已有采样；白点插值位置与屏幕曲线一致，频率标签使用同样的细黑边和阴影。音频回调及处理公式不变。
- 参数列表使用 VirtualizingStackPanel，只布局可见行，仍保留和计算完整的最多 64 段参数；IScrollInfo 使用像素单位，沿用原来的平滑滚轮。参数行按列表视口固定测量尺寸，仅列表自身的视口变化才重算行宽，不响应数值框内部冒泡的 ScrollChanged。拖动以窗口坐标追踪，提示文字出现时不会因为输入框位置变化而跳值。纵轴自动量程逐帧趋近目标，避免跨过 3 dB 量程时整条曲线突然跳变；列表直接输入有效数值时，显示曲线与量程使用 180 毫秒过渡；在目标频点上插值旧显示结果后逐帧趋向新结果，连续输入从当前曲线重新过渡。DSP 仍应用目标参数，不生成中间音频配置；数值拖动沿用直接响应及量程平滑。

- 总开关、前级 -20 至 10 dB，输入、粘贴、滚轮和配置导入共用此前级范围，超限导入报错；最多 64 段。频率编辑只接受数字且上限为 20000 Hz，增益编辑限制在 -20 至 +20 dB，Q 编辑最多两位小数、范围 0.1–30。已有或导入的滤波器仍按原有协议边界校验（频率 10–22000 Hz、增益 -30 至 +30 dB），Q 在编辑器中显示为两位以内的小数。
- 类型：PK 峰值、LSC 低架、HSC 高架、LPQ 低通、HPQ 高通、NO 陷波。架式滤波器使用中心频率与明确的 Q；低通、高通、陷波增益固定为 0。
- 频响预览直接调用同一原生组件，包含总开关但不包含前级，0 dB 表示滤波器的相对基线。未取得处理状态时以 48 kHz 预览，取得状态后使用实际采样率；曲线采用对数与线性采样的并集并加入各段中心。纵轴默认 ±3 dB，根据曲线高低分别按 3 dB 扩展，两侧均标出上限/下限的 1/3、2/3 横线；深陷波绘图下限 -60 dB，不改变 DSP。总开关启用时，若采样曲线峰值超过前级衰减，界面显示红色破音提示；这不是限幅，也不能保证检测出采样点之间的所有峰值。
- 图高 162 DIP，默认显示 20、30、60、100、250、500、1k、2k、4k、6k、8k、10k、12k、16k Hz，纵轴正数不带加号；0 dB 参考线加深并使用 1.35 DIP 粗细。列表占满余下空间，表头文字对齐编辑内容起点，「启用」对应勾选框中心，表头列宽随列表视口同步；行内输入框和类型框高 29.7 DIP、横向间距 15 DIP、行上下间距各 2.2 DIP；前级高 36 DIP，右侧外边距 12 DIP。数值框右半侧支持拖动：频率左右拖动，每 120 DIP 翻倍/减半，增益和 Q 向上增加、向下减少；列表数值框支持上下滚轮，每格相当于 10 DIP 的拖动增量，频率乘/除 2^(1/12)，增益加减 0.5 dB，Q 加减 0.1，沿用拖动的取整、边界和范围提示，滚轮由编辑框处理而不滚动列表；前级鼠标滚轮每格改变 1 dB。频率轴默认位于左右极限的中点；在图内按鼠标右键可归位到该中点，同时结束拖动，用 180 毫秒平滑归位，不改变滤波参数。图内向左拖动，从调整后的对数坐标逐渐过渡到高频展开坐标：20–8k 线性分配，8k 起按自然对数平滑压缩并归一化到图宽；4–6k 与 6–8k 保持等宽，并从 12–16k 划出部分宽度给 10–12k，16k 以上仍保留压缩。向右还原，频率范围和 DSP 不变。
- 模式标签为 182×38 DIP，左外边距 28 DIP，外框使用与普通按钮相同的 1 DIP、#DEE1E7 边框，每个 90 DIP 宽的选择块整块可点击，文字同普通按钮为 14，活动滑块使用控件微弱阴影；包含左边距的总占位保持 210 DIP。前级输入宽 64 DIP，与右边距 12 DIP 合计 76 DIP。滑块过渡 150 ms，下方应用按钮在 170 ms 后开始展开/收起（宽度 190 ms、透明度 160 ms），快速反向切换替换旧动画。选择器局部关闭布局取整，避免分数缩放下左右停靠的边距不同，两端均距外框 3 DIP。
- 右上角状态在所有语言下均不附加设备型号，左侧状态圆点保留。英文复合状态用 `·` 分隔，单行超过 260 DIP 时以该分隔符换成两行，不再显示行间分隔符，能放下时保持单行；简繁中文保持单行布局。
- 配置按 Dongle 上报的耳机名称作为型号标识，保存为软件根目录 `eq-config/型号名.json`，同名耳机共用，不按 MAC 区分；Windows 文件名禁用字符替换为下划线。当前协议没有独立的硬件型号字段，改名会改变配置文件选择。未确认耳机名称时禁用编辑，不使用全局配置；旧 `data/peq.json` 保留，可通过导入 JSON 读取。
- 有效编辑在停止输入约 250 ms 后原子保存；外部修改当前型号文件后约 200 ms 合并通知并同步界面。不完整输入和无效外部配置不会覆盖上一次有效配置；外部无效配置报告错误，保留编辑器现值。切换型号和退出前保存尚待写入的有效编辑。验证时 `QUESTYLE_DATA_DIR` 同时隔离 `eq-config`。
- 应用、导入、导出、安装/卸载驱动、重置/撤销、添加及删除滤波器使用软件顶部居中的短暂结果提示，成功、取消、失败分别显示当前操作的真实结果；提示左侧的圆形图标与文字统一居中，结果使用绿色圆底白色对勾，处理中及错误使用对应状态图标；提示不拦截鼠标、不改变页面布局，约 2.4 秒后淡出，切页或退出时清除。后台检测不显示此提示，详细错误保留在日志。
- 默认「实时生效」：有效编辑保存型号文件后，在已安装的 Dongle 音频端点写入 ProgramData\Questyle\peq\peq.bin。写入时先写临时文件，再用 POSIX 语义重命名替换（FileRenameInfoEx）；普通替换在音频引擎恰好打开读取时会因拒绝访问而失败，POSIX 重命名可以原子替换，正在读取的句柄继续读旧内容；切换型号、载入外部修改和端点安装/发现也写入当前配置。约 250 ms 的输入合并避免每个按键写一次；未安装时保留型号配置，不声称已处理音频。「手动保存」仍自动保存型号文件，有当前型号配置时「应用」即可点击，先保存当前值；无活动端点或未安装驱动时显示保存及真实驱动状态。驱动已安装时才写入音频配置，等待最多 2 秒确认对应版本进入处理；切回实时模式会写入当前配置。音频驱动状态可确认对应配置已加载，写入完成本身不代表实际处理已确认。
- 导入支持本项目 JSON 和文本。文本格式支持 `Preamp:`，以及带明确 Q 的 `Filter [编号]: ON/OFF PK/PEQ/LSC/HSC/LPQ/HPQ/NO Fc ... Hz [Gain ... dB] Q ...`。数值使用小数点，多次 Preamp 相加。
- 导出弹窗提供 Equalizer APO、Wavelet 和 EasyEffects。导出的是编辑器中的滤波配置和单段启用状态，总开关不作为导出预设的旁路状态。Equalizer APO 保存前级和带 Q 的文本；[Wavelet](https://github.com/Pittvandewitt/Wavelet/blob/master/docs/Import.md) 使用规定的 127 个频点，按 48 kHz 计算滤波响应并限制最低 -120 dB，结果是采样近似；Wavelet 导入时会归一化，因此不能保留前级绝对音量。[EasyEffects](https://github.com/wwmm/easyeffects/blob/master/src/equalizer_preset.cpp) 使用输出预设 JSON，两声道相同；其均衡器最多 32 段，超限时报告错误，不截断配置。超过 -36 dB 的前级衰减分配到输入和输出两个增益级。加载 EasyEffects 输出预设会使用导出文件中的效果链。
- 不执行 Include、Device、Channel、Stage、表达式、VST、卷积、GraphicEQ，以及 LS/HS 转角频率或斜率语法。遇到不支持的有效指令即报错，整次导入不替换当前编辑内容。此版本复刻的是参数均衡器核心，不是 Equalizer APO 的全部插件和配置语言。
- PEQ 页可见时每秒只读检测音频驱动绑定及目标端点的处理状态，不建立 USB 控制会话；进入页面、安装和卸载后也立即读取，不保留手动刷新按钮。目标端点专属映射文件包含错误、采样率、配置版本和最近 2 秒的处理心跳。端点已安装、APO 正在处理、特定配置已加载和真实听感通过分别表述，错误细节进入日志。

## 安装与隔离

普通启动只读取端点；点击「安装音频驱动」或「卸载音频驱动」才启动同一程序的管理员子进程。只接受活动播放端点中父实例具有 `VID_0A12&PID_4007` 或 `VID_0E6A&PID_4007` 的 GUID，多个活动 Dongle 时停止。原生 Initialize 也核对父实例，拒绝其他设备，不按默认输出或显示名匹配。

安装将 DLL 放入 Program Files\Questyle\peq，注册自己的 COM APO，并修改目标端点的效果绑定。修改前按原类型备份 LFX/GFX、SFX/MFX/EFX、复数效果槽及禁用增强值，位置为 HKLM\SOFTWARE\Questyle\Peq\Backups\目标端点。目标原 APO 从当前链路移出，避免与 Equalizer APO 叠加；其他端点与 Equalizer APO 的文件、配置均不修改。

「卸载音频驱动」恢复备份的绑定及原本缺失的值；外部程序改过绑定时停止恢复并记录错误。保留共享 DLL、COM 注册和配置，供其他已显式安装的 Dongle 端点使用。首次创建运行配置时默认旁路。

首次安装/恢复改变的是 APO 绑定，Windows 已有音频图仍可能缓存旧链路；普通参数应用由现有 APO 热更新，不需要插拔。当前产品仍只修改绑定，没有自动设备重启；安装或恢复后可能需要重新插拔 Dongle。

2026-10-26 实机刷新实验未通过：[CM_Disable_DevNode](https://learn.microsoft.com/en-us/windows/win32/api/cfgmgr32/nf-cfgmgr32-cm_disable_devnode) 停用音频功能接口被拒绝；[PnPUtil /restart-device](https://learn.microsoft.com/en-us/windows-hardware/drivers/devtest/pnputil-command-syntax) 对音频功能接口返回需重启系统，随后对 Dongle 本体也因待重启状态拒绝执行。仅重启 SWD 播放端点虽返回成功，恢复旧音效后本项目 APO 的真实回调心跳仍更新，不能代替重新加载音效链。

另准备了通过 Core Audio 原样提交现有格式属性的候选方案，编译通过，但管理员提示被取消，未执行实机验证。候选代码与原始结果保留在 reverse/analysis/peq-refresh；已撤下产品中的自动刷新调用，保留原安装行为，未打包。不能用此前重启音频服务后的回环结果替代本轮验证。

开发 DLL 尚未签名。Windows 受保护音频进程有组件签名要求，见 [Microsoft APO 实现说明](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/implementing-audio-processing-objects)。安装器只在系统已有 `DisableProtectedAudioDG=1` 时允许安装，不写这个全局设置；本次只读调查确认本机为 1。默认保护状态下的正式分发仍需符合 Windows 要求的签名部署，当前不具备该分发条件。

只处理经过系统效果链的播放；独占模式、ASIO/RAW、禁用增强可能绕过。麦克风模式切换、更换 USB 端口可能生成新端点，需要对新端点显式安装；不后台接管 USB，不自动改其他端点。

## 开发与验证

普通应用构建会编译原生 DLL，不安装或注册 APO。编译工具使用 [llvm-mingw 20261020 ucrt x86_64](https://github.com/mstorsjo/llvm-mingw/releases/tag/20261020)，解压到 `reverse/tools/llvm-mingw-20261020-ucrt-x86_64`，再按开发文档执行 `dotnet build`。工具不作为运行依赖，不运行发布脚本。

原生检查需要 Microsoft Win32Metadata 的 [audioenginebaseapo.h、audiomediatype.h、AudioAPOTypes.h](https://github.com/microsoft/win32metadata/tree/main/generation/WinSDK/RecompiledIdlHeaders/um)，原样放到 `reverse/analysis/equalizer-apo`。生产组件声明最小 ABI，检查程序用独立 SDK 声明核对布局并调用 COM。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/Questyle.Peq.NativeVerification/verify.ps1 -DataDirectory reverse/analysis/peq-verification
```

检查程序只在给定目录创建配置/状态文件，直接调用 APO；不注册、不修改音频端点、不播放、不接管 USB。UI 检查继续使用独立 QUESTYLE_DATA_DIR 和已有无窗口程序。代码职责：`MainWindow.Peq.cs` 编辑器，`PeqSettings.cs` 参数/文本/二进制格式，`PeqEndpoint.cs` 只读检测和状态，`PeqInstallation.cs` 显式安装/恢复，`Questyle.Peq.Native` 原生 COM/DSP。

本机管理员安装/恢复、audiodg 实际加载及 Dongle 播放端点的 48 kHz/双声道 WASAPI 回环测量通过。修正 Windows 引擎以 COM 聚合创建 APO 的生命周期处理，并修正管理员子进程不继承隔离数据目录的问题，数据目录现由参数显式传入。

旁路测得约 0 dB；前级 -6 dB 测得约 -6 dB；前级 -6 dB 加 1 kHz/+6 dB/Q1 时，1 kHz 左声道约 0 dB，4 kHz 右声道约 -5.5947 dB，与计算一致。处理时同时确认真实端点状态文件中的配置版本、采样率和心跳。测试信号峰值仅 0.003，没有调整系统音量。
